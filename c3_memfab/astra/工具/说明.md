# 生成与验证脚本

脚本以自身位置解析交付目录，财务来源仅为`交付/数据/`的已存档接口响应。

- `build.py`：重新生成正式Excel、DOCX、决策日志和网页数据。
- `check_finance.py`：对照原数检查报表、公式、图表和文档；需要先用LibreOffice在`检查/重算/`生成重算副本。它会生成用于假设联动验证的副本。
- `check_web.py`：使用Chrome与Playwright验收本地8080端口，输出截图和JSON结果。
- `play.py`：本局接口操作留档脚本。游戏已经结束，不应再次提交决策；不得新建或重跑本局。

复现生成环境：在工作目录中使用`python3 -m pip install --target 交付/工具/依赖 -r 交付/工具/requirements.txt`安装依赖，再运行`python3 交付/工具/build.py`。依赖目录是临时构建环境，交付时已移除。网页本身不需要Python包，仅需静态HTTP服务。

浏览器核验还需本机安装Chrome；办公重算需LibreOffice命令`soffice`。所有运行时画像、缓存或临时副本应设在当前工作目录中。
