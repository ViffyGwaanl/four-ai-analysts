# 本地运行

在此文件夹运行 `python3 -m http.server 8080 --bind 127.0.0.1`，再用浏览器打开本机 8080 端口的 `index.html`。也可以使用任意静态 HTTP 服务器。请通过 HTTP 打开，不要双击 HTML 使用 file 协议。

网页完全使用本地数据和库文件，无 CDN、外部字体、远程图片或运行时网络依赖。Three.js 固定为 0.170.0，许可证见 vendor/THREE-LICENSE.txt。

- 拖动时间轴或点击季度编号，查看任意一季。
- 点击播放，从当前季度向后播放；停在 Q16 时会从 Q1 重新播放。
- 拖动工厂旋转，点击房间标牌切换右侧详情；支持俯视、缩放和复位。
- 手机页面自动重排；数值保留，建筑为示意。需要支持 WebGL 的浏览器。
- 金额统一为十亿美元，产量为千片；`data.js` 由 `数据/完整导出.json` 生成，与 Excel 源数据一致。

数据反映已经完成的游戏历史，不提供未来预测，也不是投资建议。
