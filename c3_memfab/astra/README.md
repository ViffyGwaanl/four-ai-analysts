## 启动3D网页

在当前工作目录运行：

```sh
python3 -m http.server 8080 --bind 127.0.0.1 --directory 交付/web
```

然后在浏览器地址栏输入 `http://127.0.0.1:8080/`。已有服务占用8080时可改为其他本地端口。请通过HTTP打开，不要双击HTML。

初始显示Q16。点击播放会从Q1回放；支持倍速、暂停、季度滑块和季度按钮。点击房间标牌可以查看对应指标。所有网络请求均为本地静态文件。

- 正式财务数据：`数据/完整导出.json` → `history[季度−1]` → `income_statement`、`balance_sheet`、`cash_flow`。
- 生产和市场：同一条历史的 `operations`、`market`；决策来自 `decision`。

## 事实、假设与估算

蓝色是输入事实，浅绿色是公式，浅黄色是可改分析参数。修改参数影响相应分析，不改写已发生历史。

1. 存货周转天数使用平均普通库存净额÷总销售成本×90天。90天是**假设**；成本未分产品披露，因此是混合成本近似值。
2. 单季ROE使用本季净利÷平均权益；简单年化乘4，4为**假设**，不是实际年回报。
3. 收入压力情景默认下降20%，假设总成本、费用、利息、折旧和营运资金不变；税率15%为规则事实，仅对盈利征税。B8可修改收入降幅。
4. 分析现金缓冲设3.0十亿美元，是**管理假设**，不是规则0.5紧急授信触发线。
5. 复盘中Q14/Q16转产机会成本合计1.0200税后利润是**事后局部估算**，假设同等产量转产不改变总成本和市场价格，未由引擎重跑验证。
6. 净负债=普通借款+紧急借款−现金；自由现金流=经营现金流−资本开支。
7. 存货跌价已含在销售成本里，不能再扣一次；现金流重构使用净库存变化，不重复加回减值。
8. 3D建筑、物件、亮度和分档尺度为**视觉示意**。数字是真实游戏输出，建筑不是实际厂区设计，物件数量不是精确财务比例。
