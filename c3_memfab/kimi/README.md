## 文件清单

- `决策日志.md`：逐季记录决策前可见信号、判断、六项决策、理由、实际结果与教训；16 季齐全。
- `三张表.xlsx`：7 个工作表，包括使用说明、输入数据、利润表、资产负债表、现金流量表、分析和校验。分析页含毛利率、存货周转天数、经营现金流、净负债、年化 ROE、HBM 收入占比及 4 张图表。
- `经营复盘.docx`：9 页董事会复盘，包含经营阶段、决策得失、现金桥、风险、重做方案、逐季摘要和来源说明。
- `web/index.html`：3D 剖面工厂入口。包含洁净室、仓库、HBM 产线、董事会会议室、金库与扩产单元；支持季度播放、时间轴拖动、视角切换、旋转和缩放。
- `web/data.js`：网页使用的 16 季数据，由导出数据和逐季信号生成。
- `web/vendor/`：固定版本 **Three.js 0.160.0** 本地库及许可证；运行时不依赖外网 CDN。
- `data/export.json`：最终导出的 16 季完整记录、期末结果和累计净利润，是实际经营数字的主来源。
- `data/q00_state.json`：期初余额、初始市场信号和决策边界。
- `data/q01_result.json` 至 `q16_result.json`：逐季决策回执及下一季可见信号；`q01_state.json` 至 `q16_state.json` 为对应状态留档。
- `tools/`：生成 Excel、董事会复盘和网页数据的脚本，便于复现；不是打开交付物所必需的依赖。

## 网页打开方式

在当前项目目录运行：

```bash
cd 交付/web
python3 -m http.server 8000
```

然后在桌面或手机浏览器访问 `http://127.0.0.1:8000`。请通过本地 HTTP 服务打开，不要直接双击 HTML。页面不需要联网。

## 假设与分析口径

- 逐季需求预测属于经营时的**假设**，已在日志相应季度明确标注；实际需求和实际结果以回执为准。
- Excel 中黄色为事实输入、绿色为公式、蓝色为情景假设。分析页默认选择 Q16，价格与成本变动均为 0、所得税率为 15%；修改蓝色单元格会联动情景结果。
- Excel 情景分析只调整价格、销货成本和税率，其他项目不变，情景权益按净利润差额估算；它不是重新运行引擎的结果。
- 存货周转天数 = 平均存货 ÷ 不含存货跌价的销货成本 × 90 天；年化 ROE = 当季净利润 × 4 ÷ 期初、期末平均股东权益。
- 净负债 = 普通债务 + 紧急债务 − 现金，负数表示净现金。
- 引擎 `cogs` 已包含存货跌价，Excel 将其拆成“不含跌价销货成本”和“跌价损失”后再加总，避免重复扣减。
- 净利润引用引擎披露输入，以保留其四位小数舍入口径；情景净利润以实际值为基数，仅计算假设导致的变动。
- 董事会复盘中的“Q1 完成全部 HBM 投入、可能提前到 Q4 量产”及相关收入测算是**反事实假设**，未重新运行引擎，未扣除成本、产能挤占、税费和融资成本。
- 复盘提出的 20 亿美元内部现金安全线属于未来管理假设，不是引擎规则；引擎紧急授信触发线为 5 亿美元。
- 网页的空间大小、设备数量、现金堆和动画为视觉映射；现金堆采用对数映射，精确数值以面板、Excel 和导出数据为准。

## 未能核实与边界

- 未来价格、需求和反事实决策结果无法在本局结束后继续核实，不作为事实陈述。
