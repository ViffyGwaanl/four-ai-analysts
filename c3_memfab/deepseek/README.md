## 2. 怎么打开

### Excel
直接用 Excel 或 LibreOffice 打开 `三张表.xlsx`。工作簿设置了打开时全量重算；若本机未自动重算，按 `Ctrl/⌘ + Shift + F9` 强制重算。

- **蓝色底纹**：引擎导出的原始数据（输入格）。
- **黄色底纹**：可修改的假设与参数（如基准价 24.0、可变成本 5.0、税率 15%、利率 1.5%/0.8%、周转天数口径 90）。
- **绿色底纹**：公式格。改黄色或蓝色格，三张表、比率、模型校验和敏感性会自动联动。
- 单元格出现 `—` 表示该季无有息负债，流动比率不适用；`#DIV/0!` 等错误值在最终工作簿中为 0 个。

### Word
直接用 Word 或 LibreOffice 打开 `经营复盘.docx`。A4、16 页；图表为嵌入 PNG，表格为原生 Word 表格。

### 3D 网页
在 `交付/web/` 下启动任意本地静态 http 服务，例如：

```bash
cd 交付/web
python3 -m http.server 8766
```

浏览器打开 `http://127.0.0.1:8766/`。不要直接双击 `index.html`（ES module 与 import map 需要 http 协议）。

- `▶` 播放 / 暂停；左右按钮逐季；拖动底部滑杆跳转；点击 Q1–Q16 刻度跳转。
- 拖动旋转、滚轮缩放；点击 3D 标签或厂房区域打开详情面板；`重置视角`回到全景。
- 桌面推荐 1920×1080；手机 390×844 已适配（面板下移、标签隐藏、像素比封顶）。

## 4. 我做了哪些假设

### 4.1 从报表反推的模型参数（已在 Excel 与 Word 附录逐季校验）

| 参数 | 取值 | 依据 / 校验 |
|---|---:|---|
| 普通内存基准价 | 24.0 百万美元/千片 | Q1 收入 4.608 ÷ 240 千片 ÷ 0.80 = 24.0；16 季重算最大误差 0.0004 十亿美元 |
| 可变成本 | 5.0 百万美元/千片 | 单位成本 = 5 +（折旧 + 1.0）×1000 ÷ 产量；最大误差 0.0005 |
| 季度固定制造费用（不含折旧） | 1.0 十亿美元 | 同上；与折旧一起构成固定成本 |
| 折旧 | 20 季直线 | 与引擎逐季折旧一致 |
| 维持性资本开支 | 1.5 十亿美元/季 | 规则「每季先要 15 亿美元维持现有产能」 |
| 所得税 | 15%，亏损不征 | 与引擎逐季税额一致（误差 0.00005） |
| 借款季利率 | 1.5%，按期初借款 | 与引擎净利息逐季一致（误差 0.00005） |
| 存款季利率 | 0.8%，按期初现金 | 同上；不是 1.0%，由 Q13–Q16 利息收入反推 |
| 存货跌价 | 市价 × 95% | 与 Q2–Q4 跌价金额逐季一致 |

这些是**假设**，不是引擎源码；游戏规则只给了利率、税率、折旧年限等文字，具体口径是从 16 季报表行为反推的。

### 4.2 复盘测算中的假设

- **HBM 估算毛利 137.61**：引擎不单独披露 HBM 的 COGS。按「HBM 销量 × 全公司平均单位成本（累计 COGS ÷ 累计销量 15.71）」估算，HBM 毛利率约 90.1%，占全部毛利 225.84 的 60.9%。若 HBM 实际成本略高，该数会略低。
- **库存贡献 14.51**：把 Q8–Q14「普通内存销量超过当期普通内存产量」的部分（合计约 418 千片）按（当期 ASP − 可变成本 5.0）估算，假设库存为零时这些销量无法从别处补足，且未扣固定成本与税。
- **Q1 满产机会成本 0.5–0.9**：假设 Q1 满产 300 千片、多出的 60 千片在 Q2–Q4 以平均约 13.0 卖出，并考虑多计提的跌价。
- **Q10–Q12 扩产修正 +12.4**：假设 Q10、Q11、Q12 的 capex 分别从 1.5、4.0、1.5 提到 6.0（多 11.0），不提前还债（负债保持 16.0）；新增 37.5、16.7、37.5 千片/季，分别于 Q14–Q16 投产；按 Q14–Q16 普通内存 ASP 63.6/93.6/109.2、可变成本 5.0 计算，新增毛利 16.55、折旧 1.10、税前 15.45、净利 13.13；扣额外利息 0.75（税后）后净增 12.38，期末权益约 221.2。叠加 Q1 满产（+0.7）与 HBM 精确份额（+2.2）后约 **224**，权益倍数约 **6.41×**。这是事后测算，不是引擎重跑。
- **HBM 末段超配机会成本约 2.2**：按 Q11–Q16 多产的 HBM 千片 ×（当期普通内存 ASP − 单位成本）估算，假设普通内存需求足以吸收这些被挤占的产能。
- **网页视觉映射**：库存 → 仓库箱堆高度；HBM 产量 → 产线芯片数量/传送带速度；现金 → 金库金条数量（对数刻度）；有息负债 → 红色债券柱；开工率 → 洁净室设备亮度与机械臂速度；净利润 → 董事会屏幕曲线。这些是**视觉编码**，不是会计数字的精确物理还原。

### 4.3 Excel 口径假设

- ROE：单季净利润 ÷（期初、期末平均股东权益）；年化 = 单季 × 4。
- ROA：单季净利润 ÷（期初、期末平均总资产）× 4。
- 存货周转天数：平均存货 ÷ 营业成本 × 90。
- 净负债：借款 + 紧急授信 − 现金；负数为净现金。
- FCF：经营现金流 − 资本开支。
- 资产负债率：有息负债 ÷ 总资产（不是全部负债；本局无经营性负债）。
- 流动比率：流动资产 ÷ 有息负债；Q13–Q16 无有息负债，显示 `—`。

## 5. 还有哪些没能核实 / 局限

1. **引擎内部实现没有读取。** 按任务要求，只通过 `GET /state`、`POST /decide`、`GET /export` 和 `/rules` 了解市场与账务，没有尝试读引擎程序或数据文件。反推参数虽逐季吻合，但仍是对引擎行为的近似描述，不是官方口径。
2. **HBM 成本分摊未单独披露。** HBM 毛利 137.61 是按平均单位成本估算，若引擎对 HBM 有额外工艺成本，实际毛利会低于该值。
3. **修正路径不是引擎重跑。** 所有「如果重来」的期末权益（约 224）都是用反推模型做事后测算；它假设新增产能按普通内存 ASP 卖出、需求足以吸收、税率与折旧口径不变。真实重跑可能有差异。
4. **未来市场不可预测。** 16 季的价格、需求、HBM 需求都是引擎给定的路径；本复盘不构成对真实内存周期或任何公司业绩的预测。
5. **网页的 3D 表现是示意。** 工厂布局、设备数量、金条数量、库存箱数均为视觉编码；只有 HUD、标签、详情面板里的数字来自 `data.js`，与 Excel 同源。
6. **没有外部审计。** 这是一次单人经营模拟复盘，没有第三方对引擎公平性、数据完整性或会计处理做审计。
