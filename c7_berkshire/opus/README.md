## 二、怎么打开

- **Excel**：Excel / WPS / LibreOffice 均可。文件内已存有重算后的结果，打开时也会自动全量重算。改“假设与参数”表里的黄色格子（如 `A_h2`、`A_rate`、`A_tax`），“分部利润”的 2026 全年化列、“变化”页 H 节和相关图表会跟着变。
- **备忘录**：Word / WPS / LibreOffice。
- **网页**：需要用本地 http 服务打开（浏览器不允许直接双击用 `file://` 加载 ES 模块）：

  ```bash
  cd 交付/web
  python3 -m http.server 8000
  # 然后在浏览器打开 http://localhost:8000/
  ```

  操作：鼠标点选，或键盘 `1–4` / `A–D` 选择、`回车` 继续、`H` 翻锦囊（每局 3 次）。右上角可关闭声音。设备不支持 WebGL 时自动切换为 2D 模式，题目与结算不受影响。

## 四、做了哪些假设（与披露事实分开）

Excel 中假设一律为黄底（输入）或橙底（受影响的结果），并在“假设与参数”表集中说明：

1. `A_h2 = 1.0`：2026 下半年经营利润 = 上半年 × 系数，只用于“2026 全年化（示意）”列，**不是预测**。
2. `A_rate = −1.00` 个百分点、`A_tax = 21%`：现金及国债利息收入的利率敏感度示意（约 28.4 亿美元/年，税后）。
3. 2021–2023 年末资产负债表未单列“待付国债购买款”，按 0 处理。
4. “回购均价 ÷ 期末每股账面价值”用期末数近似回购当时的账面价值，仅描述执行价与账面价值的关系，不评价股价高低。
5. “前五大合计金额” = 披露的四舍五入比例 × 组合公允价值，属推算的近似值。
6. 浮存金成本 = −税前承保利润 ÷（期初 + 期末浮存金）/2，平均方法为假设。
7. 披露参数（不是假设，但集中放在同一表便于引用）：1 股 A 类 = 1,500 股 B 类；回购不让现金及国债低于 300 亿美元。

游戏中的主观设计：每个选项的“契合度分值”（100 / 部分分 / 0）、五个维度的划分、称号分档，是作者依据股东信内容做的教学设计，不是巴菲特或公司的说法；英文引文为原文照录，中文译文为作者翻译；“情境”文字是对股东信内容的转述。

## 五、口径说明与没能核实的地方

- **只以材料为准、未与 SEC EDGAR 交叉核对**：2025 年 10-K、2026Q2 10-Q、业绩公告与 2025 年致股东信（阿贝尔署名）中的内容——包括 OxyChem 与 Taylor Morrison 收购、东京海上再保险协议、CFO 交接、PacifiCorp 山火诉讼进展——均直接采用材料原文，没有用其他外部来源另行核实。
- **2021–2022 年数据来自联网下载的官网年报 PDF**（不在材料中）。分部利润与 2021 年末股东权益采用 2023 年年报中按 LDTI（ASU 2018-12）追溯调整后的数字；2021 年末原始披露的股东权益为 506,199 百万美元（调整后 501,568），两者均列在 Excel 中。2021 年末总资产为调整前口径。
- **“其他”口径**：2025 年年报把权益法投资收益并入“其他”；2021–2022 年由 2023 年年报的“非控股企业 + 其他”两行相加得到（公式）。Pilot 2023 年起并表，计入制造服务零售。
- **浮存金是约数**（公司以“约 X 十亿美元”披露），每股账面价值、比率等由此计算的结果相应是近似值。
- **主要持仓逐家金额并不齐全**：2024 年末逐家公允价值在所用材料中未披露，留空；2022–2023 年金额来自年报脚注，以十亿美元四舍五入。2026-06-30 只披露了前五大名单与合计占比。
- **Taylor Morrison**（2026-07-24 完成）发生在资产负债表日之后，未体现在上半年数字中。
- **股东信文件**：`材料/股东信` 中 1977、1979、1981、1984、1986、1988、1990、1991、1994、1997 年的 `.html` 文件实为 Brotli 压缩字节，已在 `_work/` 中解压副本后阅读（原文件未改动）；部分 HTML 为 Windows-1252 编码，已按该编码读取。20 段引文全部在提取文本中逐字找到（仅规范化了弯引号与空白），且每段不超过两句。
- **网页测试范围**：用本机 Chrome + Playwright 测试了 1920×1080 桌面（Apple M4 / Metal，约 60 fps）、iPhone 13 竖屏与横屏模拟、以及禁用 WebGL 的 2D 兜底，均完整通关、控制台无错误和警告、无失败请求。未在真实手机、Safari、Firefox 或低端安卓设备上实测。
- **Excel 缓存值**由 LibreOffice 重算后写回；Excel 打开时会重新计算。图表字体使用“Microsoft YaHei”，没有该字体的系统会自动替换。
