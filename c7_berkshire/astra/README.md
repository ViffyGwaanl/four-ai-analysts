# 伯克希尔：账本、研究与历史决策

所有成品位于此目录。先看 Excel 的「阅读指南」和「变化」，再读备忘录；网页是一款独立的历史学习小游戏。

## 文件

| 文件 / 目录 | 内容 |
| --- | --- |
| `伯克希尔账本.xlsx` | 13张工作表；2021—2025年度、2025H1比较期、2026H1；399个公式，272个输入的逐格来源记录；4张图表。 |
| `研究备忘录.docx` | 交接后的经营、资金用途、保险/铁路/能源、每股账面价值、后续研究问题和证据边界。 |
| `web/index.html` | 「时间的合伙人：和巴菲特一起做决定」入口，十道有股东信依据的历史选择题。 |
| `web/app.js`、`style.css` | 原创几何微缩小镇、列车与风机动画、答题、原文揭晓、结果及逐题复盘。 |
| `web/decisions.json` | 十题内容、实际决定、原因、原文与出处；与Excel「历史决策」一致。 |
| `web/vendor/` | Three.js固定版本0.170.0，本地库及MIT许可；无需外网CDN。 |
| `验收/` | 浏览器截图、网页测试记录、公式/文档检查记录及备忘录HTML阅读校样。阅读校样不是Word排版截图。 |
| `工作底稿/` | 结构化财务输入、来源索引、公式清单及生成/验收脚本；保留可追溯研究过程。 |

任务清单只要求XLSX、DOCX与网页，因此没有另做PPT。

## 打开小游戏

在**当前交付目录**运行：

```sh
python3 -m http.server 8917 --bind 127.0.0.1 --directory web
```

然后在浏览器打开 `http://127.0.0.1:8917`。若端口被占用，换一个空闲端口。不要用双击文件的方式打开，否则浏览器可能阻止本地JSON读取。

网页的Three.js、脚本、样式和题库全部在本地。无外部字体、图片或外网请求。可用鼠标/触屏选择，也可按1、2、3答题；支持减少动效、历史档案、断点继续、重玩与逐题复盘。若浏览器无法创建WebGL场景，会显示提示，答题仍可继续。

游戏年份：1967、1972、1983、1985、1994、1995、1998、2008、2009、2011。每题匹配实际选择得10分；得分只表示历史选择一致程度，包含历史错误，不是投资水平或收益预测。1967等题引用后来的回顾信，决定年份和信件年份分别标注。1995 GEICO为决策年，1996年初交割；2009 BNSF达成协议，2010年完成。2011年的回购价格条件仅为当年历史，不用于判断今天的股票。

## 模型口径及假设

- **利润**：税后归属股东的MD&A分项；另外提供税前法定分部。2021—2022使用2023年报会计准则重述数据，非控制业务重分类至其他；2023 Pilot纳入制造服务零售。没有把税前与税后相加。
- **同比**：2026H1对2025H1，不与全年相比；另列期末数较2025年末变化。负数或零基数的增长率写“不适用”，绝对变化仍列示。2021缺2020比较期，不编造同比。
- **现金**：合并现金及等价物加资产负债表单列短期国债，含铁路能源、不含受限现金，未扣国债未结算应付款。与管理层“保险及其他净额”区分，不重复计入现金等价物中的国债。
- **组合**：Note 4权益证券的行业公允价值，包含该口径中的优先股/认股权证，排除权益法投资。组合市值变化不等于交易净买入。
- **浮存金**：保留披露约数。2025年末年报约176,000百万美元，2026季报称期末177,500、增加约1,100；两期粗粒度余额差1,500不能替代披露增量。没有把反推的176,400当披露事实。
- **回购**：2026H1入账4,762百万美元，现金支付4,444，差318；两者分别列示。缺少逐笔结算明细，没有断言差额全部来自某一种因素。
- **每股账面价值**：股东权益除以期末A股加B股/1500；B类每股数再除1500。使用精确换算的期末等值股数，不使用EPS加权平均股数。
- **唯一敏感性情景**：假设6月末现金加国债固定，80%同步重定价、收益率下降100基点、持续半年、边际税率21%。橙色格可调，税后影响及变化页联动。该情景不是公司预测。所有其他披露数据均以浅蓝输入格列示，公式浅绿。
- 汇兑与灾害调整是公开数据的观察性算式，未被写成公司披露的“有机增长”或“正常化利润”。管理层资本支出展望标明为展望；2026年7月的期后收购不计入H1现金流。

## 验收与限制

- XLSX与DOCX通过ZIP完整性检查，并分别用openpyxl、python-docx成功打开。
- 独立公式求值器复算全部399个公式，与写入的缓存结果一致，没有错误值；利润、行业组合和税前分部加总通过。
- 将收益率假设从−1%改为−2%后，税后影响由−1,155.02424变为−2,310.04848百万美元，分析页同步变化。
- 网页通过本地HTTP服务进行1920×1080桌面与390×844手机验收；详见`验收/网页验收.json`及截图。
- 没有Microsoft Office/LibreOffice图形程序的打开与分页验收，不能声称已在这些应用逐页检查；提供了标准OOXML成品和结构/公式检查。变化页设置为单页横向打印。
- 未独立审计提供的2025/2026材料的真实性；未核实未披露交易意图、精确未取整浮存金或回购差额逐笔成因。部分早期HTML文件不可读，未用于游戏证据。
- 未另附完整外部年报副本，避免其原有标志、联系方式进入交付物；章节和网页足以追溯。

## 复核脚本

`工作底稿/build_data.py`保存财务输入，`build_workbook.py`和`build_memo.py`生成成品，`validate_workbook.py`复算公式并检查文档，`test_web.cjs`进行浏览器验收。结构化输入和当前成品不需要安装额外软件即可阅读。重跑Python脚本需将`requirements.txt`中的库安装到`工作底稿/依赖`，从本项目根目录运行脚本；浏览器脚本需Playwright及相应Chromium环境。临时依赖、浏览器下载与未筛选原文不随成品交付。
