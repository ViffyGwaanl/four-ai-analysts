## 打开网页

在当前任务目录运行：

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory 交付/web
```

在浏览器访问 `http://127.0.0.1:8000/`。不要直接双击HTML以 `file://` 方式运行，浏览器会限制模块与数据加载。

- 滚动页面逐层拆开磁体、真空室、包层、偏滤器；也可点击步骤、用鼠标拖动旋转、复位或暂停动效。
- 第二部分切换2024来源分摊、2030基准、低需求和高需求情景。
- Three.js固定为 **0.170.0 / r170**，库和MIT许可均在 `web/vendor/`，页面不请求外网CDN。
- 网页只显示来源名称与日期，没有可点击的外部来源链接；完整网址在报告、Excel和数据底稿。
- 图为商业D–T托卡马克概念剖面，非工程比例或特定机型复刻；ITER不发电，Helion直接电能回收也不是图中热转换路线。

## 假设与事实的边界

1. **2030供电结构为研究假设**：煤18%、气26%、核裂变14%、可再生40%、聚变0%，其他为2%残差。不是IEA逐燃料预测；需求总量才参考IEA新版950 TWh。
2. **低高情景为研究敏感性**：基准×80% / 120%，即760 / 1,140 TWh，不是IEA官方情景。
3. **2024供电结构为约数分摊**：IEA列示煤30%、气26%、核15%、可再生27%；其他取残差。聚变零值为模型处理。以415 TWh终端用电分摊，不与460 TWh发电端口径混加。
4. **成本算例为独立假设**：1 GW IT、85%平均负载率、PUE 1.20、8,760小时，得到8.9352 TWh。60/90/120美元每MWh是电价假设，非市场报价或特定PPA价格。
5. **核电、光伏容量因子及燃气超配均为算例假设**：90%、25%、35%。计算年电量等效容量不意味着逐时保供能力相同。
6. **聚变不计入2030基准供电**：不是断言2030不会出现任何示范；公司融资、购电安排与科学目标均单独列示。
7. 动画线路宽度随电量变化，光点速度只表示流向；电网是简化输送层，储能不作为一次能源重复计量。几何尺寸与部件数量不是工程数据。

## 使用与更新Excel

- 蓝底：披露或统计输入；橙底：研究假设；绿底：公式。6页分别为明细、假设、模型、电力流向、汇总、来源索引。
- 在“假设”页修改参数后，模型、流向、汇总和图表会自动重算。检查模型K32是否“通过”，流向校验是否为零。
- 网页是Excel已保存结果的快照。修改Excel后，在Excel或LibreOffice中重算并保存，然后运行：

```sh
python3 交付/工作底稿/同步网页.py
```

该脚本只用Python标准库，直接读取XLSX公式缓存、检查守恒，更新 `web/data.json` 并写入工作簿SHA-256。没有缓存、结构超限或错误值时会停止，不把缺失结果当零。

报告和PPT为交付时静态版本；同步网页不会自动重写其文稿。**修改假设后，如用于对外展示，须同时更新并复核报告与PPT。** 原始生成脚本保留用于复现，重新运行“建立数据.py/生成表格.py”会回到交付基准并覆盖工作簿，不适用于保留用户改动。
