READ BEFORE USE

四个必须保留的边界

  1. 415 与 460 TWh分别是终端用电和发电侧供电量，不能混用。
  2. 物理与合同结构不同。100% 年度匹配不代表每小时同一电源。
  3. 功率与电量不同。MW 是瞬时能力，TWh 是一段时间的累计电量。
  4. 聚变里程碑不等于净上网电力；未来时间表均为公司目标。
