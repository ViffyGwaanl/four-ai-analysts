# AI 的电从哪来｜交付说明

版本与网络访问日期：**2026-10-22**  
本交付用于能源与科技行业研究和展示，不构成投资建议，不含证券评级、目标价或估值判断。

## 1. 文件清单

- **`研究报告.docx`**：28 页中文行业研究，含 4 张同源图表、27 个表格和完整来源索引。覆盖全球数据中心用电与 2030 预测、科技巨头资本开支、供电路径、核电长期 PPA、聚变融资与时间表、成本瓶颈、价值链和跟踪指标。

- **`web/app.js`**：3D 场景、滚动拆解、部件标注、能源筛选和响应式逻辑。
- **`web/styles.css`**：桌面与手机视觉样式，含减少动态效果支持。
- **`web/data.js`**：与 Excel 同源的数据快照，不含外部链接。
- **`web/vendor/three.module.js`**：Three.js **0.170.0**，本地固定版本。
- **`web/vendor/THREE-LICENSE.txt`**：Three.js 许可证。

## 2. 打开方式

### 报告与数据表

使用 Microsoft Word、Microsoft Excel 或 LibreOffice 打开。Excel 黄色单元格为输入，蓝色单元格为公式；如应用程序未自动重算，请手动执行全量重算。

### 网页

在当前工作目录运行：

```bash
python3 -m http.server 8000 --directory 交付
```

然后在桌面或手机浏览器访问：

```text
http://127.0.0.1:8000/web/
```

也可以先进入 `交付/` 再运行 `python3 -m http.server 8000`。网页运行不依赖外网 CDN、外部字体或外部图片；直接双击 HTML 不是推荐方式，请使用本地 HTTP 服务。

网页底部的报告和 Excel 按钮是本地交付文件链接；出处只显示来源名称与日期，没有可点击外部链接。

## 5. 必须保留的口径边界

- **415 与 460 TWh**：前者是 2024 年终端用电，后者是对应发电侧供电量，含厂自用和输配损失。
- **物理与合同结构**：IEA 物理供电结构不是企业 PPA 或绿证组合；年度 100% 匹配不等于每小时 100% 无碳供电。
- **功率与电量**：MW/GW 是功率，MWh/TWh 是电量；签约 MW 不能直接当成每年恒定 TWh。
- **现有、增容与未来容量**：分开列示，不能相加为已投运容量。Crane 部分输电升级最晚 2030 年，不是重启目标年。
- **资本开支与用电**：CapEx 包含服务器、建筑、网络等，且各公司租赁口径不同，不能用固定系数直接换算电力需求。
- **聚变里程碑**：first plasma、Q>1、net facility gain、demonstrate fusion energy 不等于持续净上网电力。
- **融资口径**：承诺出资、到账资本、公共补助、项目资本开支、可提取额度和合并估值不混算。

## 6. 未能完全核实或尚未披露的事项

- IEA/LBNL 的历史用电含模型估计，并非全球电表实测加总；不同版本和机构不作未经调整的同比拼接。
- IEA 正文未逐项列出 2030 年各能源精确 TWh，因此网页使用 2024 年物理供电约份额，而不是目测 2030 堆叠图。
- Meta 2026 年实际全年用电、其他公司统一边界的 2025/2026 数据中心实际用电尚未形成可直接比较的完整数据。
- Amazon 的可再生项目预期容量、长期合同电量和年度实际用电是不同指标，未据此反推 Amazon 年度 MWh。
- 多数商业 PPA 未公开价格、逐年电量、调整条款和全部交付条件，未估算相关收入或利润率。
- Crane 的精确重启/商运日期仍以监管与后续公司披露为准；当前状态采用 Constellation 2026Q2 原始文件。
- Helion 最终 G 轮后的累计融资未同步重述；Pacific 的承诺出资不等于全部到账；Proxima 累计资金含公共补助。
- TAE 拟议合并、可转换票据额度与 Da Vinci 时间表均附条件；采用 2026 年 S-4 的较新口径。
- 聚变项目最终净发电、并网、可用率、交付时间和成本尚不能由现有公告确认。
- Meta Environmental Data Index 使用 PDF 修订日 2025-10-17 作为版本日期；LBNL《Queued Up: 2026 Edition》出版记录仅精确到 2026-05。
