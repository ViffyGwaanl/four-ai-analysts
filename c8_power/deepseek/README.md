## 2. 怎么打开

### 2.1 文档与数据表

- `研究报告.docx`：用 Microsoft Word、WPS 或 LibreOffice 打开。
- `数据表.xlsx`：用 Microsoft Excel、WPS 或 LibreOffice 打开。汇总页与图表由公式引用明细表；修改「假设与情景」页的**黄色输入格**，汇总、图表与供给结构会自动更新。每个明细表的「来源」列同时写出来源编号、机构与发布日期；完整标题与链接见「来源清单」页。

### 2.2 3D 网页（必须用本地 http 服务）

在 `交付/web/` 目录下执行：

```bash
cd 交付/web
python3 -m http.server 8000
```

浏览器打开：

```text
http://localhost:8000/
```

不要直接双击 `index.html`（`file://` 协议下 ES module 与 importmap 会被浏览器拦截）。

**操作**：

- 向下滚动：托卡马克从整机开始，逐层拆开真空室、包层、偏滤器、磁体、等离子体、低温与辅助系统，最后到整机参数。
- 桌面端鼠标拖动 3D 模型可旋转；手机端上下滑动翻页。
- 滚到「02 电力流向」后，右下角可切换 **2024 / 2030**，数值、流量粗细、粒子速度与下方图例同步变化。
- 页面为 1920×1080 桌面优化；在 390×844 手机上不会崩、不会横向溢出。

## 4. 关键假设（与披露事实分开）

完整 31 个参数见 `数据表.xlsx`「假设与情景」页；对结果影响最大的 7 个如下：

| 编号 | 假设 | 取值 | 为什么这么设 | 影响 |
|---|---|---|---|---|
| A07 | 美国占 2030 年全球数据中心用电 | 47% | IEA 只给 2024 年 45%；美国 AI 资本开支集中，份额略升 | 美国 2030 年 444 TWh；改为 42% 则为 397 TWh |
| A22 | 2030 年美国数据中心气电占比 | 46% | 按 444 TWh × 46% = 204 TWh，较 2024 年 +130 TWh，与 IEA「+130 TWh」一致 | 气电 TWh、非化石占比 |
| A23 | 2030 年可再生占比 | 33% | 较 2024 年 +102 TWh，接近 IEA「+110 TWh」 | 可再生 TWh、非化石占比 |
| A24 | 2030 年核电占比 | 20% | 现有核电保持，SMR 2030 年前贡献有限 | 核电 TWh |
| A25 | 2030 年煤电占比 | 1% | 煤电从 15% 降至 1%，主要被气电与可再生替代 | 煤电 TWh |
| A13 | Meta 2024–2026 年用电增速 | 30%/年 | 2023–2024 年实际 +20.6%，Prometheus 1 GW 级集群 2026 年上线 | Meta 2026 年 30.5 TWh；按 20% 为 26.0 TWh |
| A14 | 核电年利用小时 | 7,884（90% 容量因子） | Constellation 2025 年实际 94.7%，90% 偏保守 | 核电 PPA 折合 TWh |

其他假设：A29 AI 数据中心单位投资 100 亿美元/GW（来自 Meta Hyperion 5 GW、>500 亿美元）；A30 资本开支中 50% 用于数据中心土建与供电；A31 欧元兑美元 1.08；A08/A09 全球用电量 27,000 / 33,000 TWh（用于计算占比）。

**重要**：美国 2030 年 444 TWh 是**本报告的情景**，不是 IEA 的国别预测，也不是任何公司的指引。IEA 只给出全球 2030 年 945 TWh 与 2024 年 45% 的美国份额。

## 5. 未能核实 / 需要谨慎使用的地方

1. **PPA 价格**：Constellation 与 Meta/Microsoft 均未披露价格。约 80 美元/MWh 与 ≥110 美元/MWh 是 Jefferies 分析师估算（S23），不是公司披露。其他交易的 PPA 价格均未披露，本报告留空，未用假设替代。
2. **Meta 2026 年用电**：30.5 TWh 是本报告按 2024 年披露值外推的估算，不是公司指引。Meta 只披露到 2024 年（2025 年环境数据索引）。
3. **美国 2030 年份额与电源结构**：A07、A22–A26 是本报告假设；IEA 的 2030 年国别拆分与电源结构没有公开到本报告需要的粒度。
4. **五大科技巨头 2026 年资本开支**：除 Meta 取自 10-Q 外，Amazon / Microsoft / Alphabet / Oracle 的数字来自公司指引的媒体汇总（S27–S29），未逐份核对原始财报；口径（自然年 vs 财年）已在表中标注。
5. **聚变公司估值、融资与时间表**：来自公司公告、FIA 报告与 Nuclear News Network 数据库，未做独立尽调；时间表是公司目标，不代表已实现。
6. **部分交易规模为「约」或「>」**：例如 Meta–Vistra「>2.1 GW」、Meta 最高「7.7 GW」，本报告按 2.1 GW 与 7.7 GW 入表；TerraPower 选择权 2.1 GW 未全部计入首批。
7. **数据截止**：2026-10-22 之后发生的事件（项目投产、价格变化、政策调整、公司指引更新）未纳入。

## 6. 网页技术说明

- **Three.js 版本**：r169（`three@0.169.0`），库文件在 `web/vendor/three/`，通过 importmap 本地加载；无外部 CDN、无外部字体、无外部图片。
- **场景一：托卡马克拆解**：程序化几何（D 形真空室、包层瓦片、偏滤器 cassette、16 个 TF 线圈、6 个 PF 线圈、中心螺线管、低温恒温器、等离子体环），滚动驱动逐层爆炸；每个部件有 3D callout + 左侧说明卡 + 右侧部件索引。
- **场景二：电力流向**：6 个节点（天然气、可再生、核电、煤电、其他、聚变 ghost）向数据中心汇聚；2024/2030 切换时，管道半径、透明度、粒子速度、标签与 HUD 同步更新；聚变按 0 TWh 处理，用虚线/淡色表示「尚未商业上网」。
- **数值一致性**：`web/js/data.js` 由与 `数据表.xlsx` 同一套 Python 数据模型生成；关键值（415、945、1,200、186.75、444.15、74.7/44.8/37.4/28.0/1.9、204.3/146.6/88.8/4.4/0.0、7.7 GW、142.4 亿美元）与 Excel/文档一致。
- **性能**：本地测试 1920×1080 与 390×844 均约 60 FPS；无横向滚动。
- **降级**：WebGL 不可用时显示 `webgl-fallback`，仍可阅读关键数字。
- **移动端**：`< 820px` 时隐藏右侧部件索引与 3D callout，改用底部说明卡；能量流标签收起，数值由底部 HUD 图例呈现；相机自动拉远。
