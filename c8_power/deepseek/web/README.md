# 3D 网页：托卡马克拆解 + 电力流向

## 运行

在本目录执行：

```bash
python3 -m http.server 8000
```

打开 `http://localhost:8000/`。不要用 `file://` 直接打开。

## 操作

- 向下滚动：托卡马克逐层拆解；左侧卡片解释当前部件，右侧索引高亮。
- 鼠标拖动：旋转托卡马克（手机端上下滑动翻页）。
- 滚动到「02 电力流向」：右下角切换 2024 / 2030；数值、流量、粒子与图例同步。
- 页面在 1920×1080 桌面与 390×844 手机上测试通过；无横向滚动。

## 数据

`js/data.js` 中的数值由与 `../数据表.xlsx` 同一套数据模型生成：

- 全球数据中心用电：415 / 945 / 1,200 TWh（IEA，2025-04）
- 美国数据中心用电：186.75 / 444.15 TWh（2030 年份额为报告假设）
- 美国数据中心电源结构：2024 与 2030
- Meta 核电规模：7.7 GW；聚变行业累计融资 142.4 亿美元

完整来源与假设见 `../README.md` 与 `../数据表.xlsx`。

## 技术

- Three.js r169，固定版本，文件在 `vendor/three/`，本地加载，不依赖外部 CDN。
- 所有几何与材质均为程序化生成，无外部图片、字体或模型文件。
- WebGL 不可用时显示降级提示。
