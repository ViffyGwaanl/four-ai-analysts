## 5. 假设、计算口径与换股结果

- 毛利=营收−营收成本；FCF=经营现金流−资本开支。SpaceX Q4经营数据=FY2025−9M2025；2026Q2/Q3 CFO和Capex由YTD差分。Tesla Q4主要由Q3 Update直接披露。
- 现金＋短期投资不含受限现金；债务为资产负债表流动和非流动债务及融资租赁账面净额，不把夹层优先股或可赎回NCI混入。SpaceX Q3未披露债务本金及债务/租赁进一步拆分。
- 合并备考不计协同、融资、税务、购买价格分配或交叉持股会计处理。已知Q3 Tesla对SpaceX Megapack收入221、成本171，模型另列“仅Q3”的抵销示例：收入由42,621变为42,400，毛利由14,591变为14,541；该示例未调整SpaceX PP&E未实现利润和折旧，不能当作正式合并分录。
- 换股结构假设：SpaceX发行Class A给Tesla股东；每1股Tesla换取X股SpaceX；溢价应用于Tesla对价。股数采用SpaceX 2026-09-30约13,579百万股、Tesla 2026-10-15约3,952.757946百万股。
- 四种方法均给出0%基准溢价，且可在「换股比例」B7:B10修改：收盘市值、20日成交量加权收盘价、LTM收入倍数（SpaceX 6.0x/Tesla 2.0x，**假设**）、LTM调整后EBITDA共同20.0x（**假设**）。倍数法是EV加现金减债务的相对尺度，非公允价值或目标价；两家公司Adjusted EBITDA定义不完全可比。

| 方法（0%溢价） | 换股比例 | SpaceX原股东 | Tesla原股东 | Musk合并后静态经济持股 |

| 收盘市值 | 2.4259x | 58.6% | 41.4% | 33.5% |
| 20日成交量加权收盘价 | 2.3646x | 59.2% | 40.8% | 33.7% |
| LTM收入倍数（假设） | 3.4324x | 50.0% | 50.0% | 31.2% |
| LTM调整后EBITDA倍数（假设） | 3.2970x | 51.0% | 49.0% | 31.5% |

Musk持股口径单独列示：SpaceX招股书IPO后实际Class A+B经济持股约46.1%（不含350百万份期权）；按较新Q3股数静态计算为44.7%。Tesla Proxy披露受益所有权19.8%（调整分母），按全部已发行股数简单计算为17.7%。合并后数值是静态经济权益桥，不是投票权预测；SpaceX Class B十倍投票权、Class B董事选举权及Tesla CEO奖励股代理投票需要法律文件确认。

## 6. 关联交易处理与未核实事项

模型「关联交易」逐笔列出Tesla/SpaceX/xAI的Megapack、车辆、广告、飞机、许可支持、应收/递延收入、SpaceX股权投资，以及Valor、Boring、Musk Industries、安保、Craft Aviation、私人飞机、Musk信托二级购股和Neuralink披露。不同披露视角（例如Tesla对xAI收入与SpaceX采购）不能简单相加。

合并时原则上：内部收入与对应成本抵销；应收应付、预收/递延项目核对后抵销；集团内资产销售评估未实现利润和折旧；Tesla持有SpaceX股权消除交叉投资并避免重复计算。Valor及其他Musk实体不会因本次合并自动成为集团内部主体。

尚未核实或材料未提供：正式合并协议和会计收购方；最终对价和股票类别权利；完整LTM内部交易总账及对应资产/折旧；购买价格分配和商誉；交叉持股的正式会计处理；SpaceX Q3债务本金/租赁拆分及change-of-control；交割后Musk实际持股与投票权；实际公众流通股；Q3 Tesla专属SpaceX采购全量金额；Cursor长期整合影响；频谱、Terafab、Macrohard的确定资本承诺。未披露不等于不存在，不对缺失金额作事实性估算。
