在本文件夹启动本地HTTP服务：

```sh
python3 -m http.server 8000
```

然后用浏览器打开 `http://localhost:8000`。不要直接双击HTML（ES模块需要HTTP）。

Three.js固定版本0.170.0，库文件和许可证在vendor中；运行时无外网依赖。推荐桌面1920×1080，手机可滚动查看，无法启用WebGL时保留财务文本和交互表。

数据来自合并模型.xlsx重算后的缓存，见data.js。Excel变更不会实时同步网页，须用工作底稿/export_data.py刷新快照。溢价滑杆按Excel同一公式计算，只改变换股情景，不改变历史财务。
