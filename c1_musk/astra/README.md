## 关键口径、假设与抵销

1. **历史口径**：FY2025和2025Q4–2026Q3四个单季。SpaceX Q4由全年减9M推导；Q2/Q3现金流由累计值差分。SpaceX历史已经包含xAI/X共同控制重组，不重复加入。Cursor仅自2026-08-14纳入，没有自造全年备考。
2. **正式分部**：Tesla汽车包含服务及其他，另有能源；SpaceX为航天、连接、SI。Tesla分部利润是毛利，SpaceX是经营利润；通过Tesla整体经营费用桥接到合并经营利润。网页的五个级身仅代表这五个分部。
3. **现金/债务/FCF**：现金与短期投资不含受限现金、数字资产或Tesla长期SpaceX投资；债务含融资租赁而不含经营租赁。SpaceX IPO前可赎回优先股在主表另列。FCF按披露资本开支计算，不代表全部投资、频谱和并购现金流。
4. **内部销售**：Q3抵销Megapack收入221与成本171，内部毛利50；9M对应626、478和148。假设相关毛利仍在资本化资产中，基准折旧回转、税收利益与协同为0。历史未实现毛利未获明细，以0占位，不表示事实为0。
5. **内部现金流**：假设SpaceX关联PP&E现金支出9M的480、Q3差分151对应Tesla收款；OCF和资本开支同时扣除，FCF不变。应计收入和现金不一致，必须进一步对账。
6. **交叉持股**：Tesla对SpaceX投资账面2,865抵销。Q3投资重估税前损失142/税后108、9M税前收益863/税后655从合并净利润中剔除。Tesla持股按招股书拆股前3.8百万股乘5估计19百万股，换股时注销，不能向自己发行。
7. **往来余额**：Tesla应收729含588未交货开票，扣后141；递延收入648扣588后60。这些仅为核对线索，未获SpaceX对方明细，模型往来匹配抵销默认0。关联Valor债务、TBC和安保公司交易保留，不因关联就合并。
8. **换股结构**：假设全股票交易，由Tesla发行，原Tesla每股保留1股；SpaceX每股同一价值，不为不同投票权单独溢价。基础溢价0%，敏感性−20%至+30%；三种方法全公式计算。
9. **倍数法**：SpaceX EV/TTM收入12×、Tesla 4×均属未经可比公司校准的假设。EV加现金减债务；Tesla另加所持SpaceX股权按同法测得的价值；其他非经营资产、少数权益及经营租赁估值调整默认0。
10. **股本与Musk**：采用9月末已发行股本Tesla 3,952.648559、SpaceX 13,579，不采用EPS加权平均股数。Musk SpaceX招股书受益持股扣350可行权期权，剩6,068.547515；假设5月至9月无净变动。Tesla可支配699.580882，未把423.743904未达标股份算入其分子，但这些已发行股份已在总分母中。统一分母下合并前占比分别44.69%与17.70%；委托书19.8%口径单独复算。
11. **股份不等于投票权或已归属收益**：SpaceX84.4%是招股书IPO后投票权。Musk股份中有未归属限制股。补充行权/奖励情景仅为固定换股比下股数示意，未计行权现金、全部员工稀释、Tesla每股334.09美元抵扣或归属法律判断，不是认定合并自动兑现奖励。
12. **备考性质**：仅账面加总及可量化抵销，未确定会计收购方、共同控制判断或购买价分摊，未计正式交易融资、税收、重估商誉或整合成本。
